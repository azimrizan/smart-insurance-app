# Smart Finance - Premium Fintech Platform

A full-stack, production-ready fintech platform with a focus on trust, security, and a premium glassmorphism user experience.

## 🚀 Getting Started

To run the complete platform, you need to start both the backend server and the frontend client.

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### 1. Start the Backend Server
```bash
cd server
npm install
npm run dev
```
The server will start on `http://localhost:5000`.

### 2. Start the Frontend Client
Open a new terminal window:
```bash
cd client
npm install
npm run dev
```
The client will start on `http://localhost:5173`.

## 💎 Features
- **Loans**: Real-time EMI calculation and formal application history.
- **BNPL**: Interest-free instalment management with credit limit tracking.
- **Virtual Cards**: 3D-effect cards with security controls (freeze/unfreeze).
- **KYC**: Comprehensive identity verification workflow.
- **Admin Suite**: Advanced management for loans, KYC, and users.

## 🛠️ Stack
- **Frontend**: Vite, React, Redux Toolkit, Framer Motion, Lucide Icons.
- **Backend**: Node.js, Express, JWT, MockDB.
- **Styling**: Premium Glassmorphism (Vanilla CSS).
